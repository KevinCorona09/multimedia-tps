# Escaneo Facial 3D Interactivo (ml5.js FaceMesh + p5.js)

Proyecto web que detecta **468 puntos faciales** en tiempo real y renderiza una **malla 3D** interactiva con **p5.js (WEBGL)**. Incluye **iluminación ambiental + direccional rotante**, **deformación por expresión** (boca abierta), **controles interactivos** (botón, slider, checkboxes) y **rotación orbital** con el mouse.

> Este proyecto sigue exactamente las especificaciones marcadas en el documento de requisitos: estructura, tecnologías, funcionalidades y UI.  

## Tecnologías
- [p5.js ≥ 1.9.0](https://p5js.org/)
- [ml5.js ≥ 1.0.0](https://ml5js.org/) — modelo **FaceMesh**
- Renderizado **WEBGL** con p5.js

## Requisitos
- Navegador moderno (Chrome, Firefox, Edge).
- Permitir acceso a la **cámara**.
- Servir el sitio por **HTTPS** o desde **localhost** (recomendado: servidor local).
